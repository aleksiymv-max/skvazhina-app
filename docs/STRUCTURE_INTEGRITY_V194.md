# Промысел v1.94 — целостность участков, кустовых площадок и скважин

## Причина
В предыдущих версиях локальное удаление структуру изменяло, но `AppStateStore.reconcileWithCurrent` и серверная функция `mergeState` выполняли объединение старого и нового списков, в результате старые снимки восстанавливали удалённые объекты.

## Исправление
- У начальника цеха доступно создание, переименование и удаление участков, кустов и скважин; права ведущих ИТР сохранены, обычный оператор не имеет прав изменять структуру.
- Переименование участка обновляет `Pad.areaName` у связанных кустов; сохраняются изменения через `commitStructureNow`.
- При создании не допускаются дубли названий внутри участка и номера скважины в рамках куста.
- Глобально уникализированы идентификаторы новых объектов с помощью времени в микросекундах и случайного суффикса.
- При удалении записываются `structureDeleted` (areas, pads, wells). Скважины идентифицируются парой `padId:wellId`.
- Клиент сохраняет tombstones локально и фильтрует их при восстановлении и обмене с сервером. Неактуальные данные с других телефонов не возрождают удалённые объекты.
- Сервер хранит подтверждённые метки в `promysel_structure_tombstones` независимо от окна последних 4 снимков. Запись разрешена только начальнику цеха / ведущему ИТР. Поддерживается изоляция по месторождению.
- Изменения не удаляют журнал обходов, историю замеров или задания.

## Проверки
- Python-скрипт применён к исходникам v1.88 и прошёл 28 статических контрактов.
- Добавлено 4 Flutter-теста, включая удаление родительского участка, отдельного куста, скважины и старый офлайн-снимок.
- Сборка Web и точная версия Cloudflare PROD должны проверяться по GitHub Actions до объявления релиза.
- Android получает общий исходный код, но APK не собирается.

Риски: старые устройства, работающие с прежним Web-кешем до обновления, временно могут видеть удалённый объект, пока не обновят приложение. Продакшен-данные для проверки не удаляются.
