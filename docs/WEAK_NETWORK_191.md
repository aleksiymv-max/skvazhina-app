# Промысел — устойчивость к слабой связи, v1.91

Изменение в общем Flutter-коде Web и будущего Android. APK не собирается.
Рабочие Cloudflare PROD, Tuqo и Supabase не изменяются.

### Поведение
- Первый вход нового сотрудника требует связи с сервером. Ранее подтверждённая сессия на том же устройстве загружает локальные данные до сетевого обновления токена.
- Запрос входа выполняется один раз за нажатие и допускает до 27 секунд; после успешного входа загрузка персонала не блокирует открытие приложения.
- Только безопасные GET повторяются максимум 2 раза при тайм-аутах / HTTP 408, 429 и 5xx. Запросы регистрации, отправки сообщений, изменения данных, подтверждения и смены токена не повторяются автоматически.
- Изменения сохраняются локально в последовательной очереди; приложение показывает ошибки локального сохранения. Отправка синхронизации сгруппирована с задержкой 4 секунды.
- Очередь замеров сохраняет стабильные идентификаторы. Для общего состояния приложения сохраняется ключ незавершённой отправки, чтобы при потере ответа сервера не создавать второй снимок.
- Сетевые повторы ограничены нарастающей паузой, состояние синхронизации показывается на главной.
- Чаты используют кратковременный кеш в памяти и повторяют только чтение; сообщения и файлы не отправляются автоматически повторно.

### Ограничения
- При первом входе нужна сеть и доступ к Supabase. Полностью заблокированный домен нельзя исправить тайм-аутами; потребуется согласованный API-шлюз.
- Web-офлайн зависит от кеша браузера/PWA. Очистка данных браузера, удаление PWA и сброс хранилища удаляют локальные несинхронизированные изменения. Не обещать полный офлайн-режим всех модулей, например недоступных ранее фотографий/чатов.
- Офлайн-сведения — сохранённый снимок последней подтверждённой сессии. Актуальность прав проверяется на сервере при восстановлении связи; отсутствует серверная авторизация при полностью отключённом интернете.
- Клиентский офлайн-кеш чатов находится в памяти и не гарантирует историю после перезапуска браузера.
- Предыдущие механизмы очереди и серверные API сохранены.
