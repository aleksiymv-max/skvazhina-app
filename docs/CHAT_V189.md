# Чат «Промысла» — общие исходники v1.89

Web и Android используют один Flutter-исходный проект и одну последовательность патчей. APK не собирается.

## Дизайн
- Читаемый текст 15,5 px с увеличенным межстрочным интервалом.
- Компактные пузырьки с адаптивной шириной, небольшими тенями и разными углами.
- Тонкие статусы: одна галочка — отправлено, две — прочитано, часы — отправляется.
- Разделители дат «Сегодня», «Вчера», календарные даты; группировка сообщений по авторам.
- Аватары собеседников показываются в конце последовательности сообщений.
- Аккуратные список чатов, поле ввода и кнопка отправки.

## Производительность
- Первичная загрузка истории и данных заголовка — параллельно.
- Когда диалог открыт, новые сообщения проверяются раз в 18 секунд инкрементально; полное согласование — раз в 15 циклов.
- Общий список диалогов обновляется раз в 120 секунд; действующий кэш и монитор непрочитанных сохранены.
- Сравнение элементов истории без создания двух больших текстовых строк.
- Поиск комнат при обновлении O(n) вместо повторного O(n²).
- Стабильные ключи сообщений сохраняют состояние виджетов вложений.

## Изоляция и тестирование
Не изменялись серверные функции Supabase, таблицы и рабочие сайты. DEV/PROD используют общую Supabase-базу; разрушительные тесты недопустимы.
Локально на сгенерированном коде v1.88 выполнены Python-синтаксис и 18 статических регрессионных проверок. Полная Flutter Web-сборка и визуальный E2E требуют работающего GitHub Actions runner; без них релиз не считается проверенным.
Исполняются оба файла из `tools`: `prepare_promysel_chat_polish_v189.py` и `test_promysel_chat_polish_v189.py`, и в Web workflow, и в архивном Android-рецепте. APK не запускается.
