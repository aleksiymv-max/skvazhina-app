ПРОМЫСЕЛ — РАБОЧАЯ Web/PWA на Timeweb без Cloudflare (стабильная версия 1.88)

Содержимое:
  site/        — полная Web-сборка, Supabase API вызывается по своему адресу (относительные пути)
  deploy/      — сервер Nginx, автоматическая установка HTTPS, проверка доступности

Назначение: самостоятельный VPS + домен, который открывается в нужной сети без VPN.
Не нужен перенос базы Supabase; DEV остаётся на Cloudflare (https://dev.promysel-web.pages.dev). Рабочая версия публикуется отдельно на Timeweb Cloud.

ВАЖНО: это ГОТОВЫЙ ПАКЕТ ДЛЯ РАЗМЕЩЕНИЯ, а не уже опубликованный новый адрес.
Нужны действующий VPS/хостинг, домен, HTTPS и возможность сервера связаться с Supabase.

1. Создайте VPS у провайдера, доступного вашим сотрудникам без VPN.
   Для предсказуемой работы Nginx рекомендован Ubuntu 24.04 и не менее 1 ГБ ОЗУ.
2. Добавьте DNS A-запись выбранного домена на публичный IPv4 VPS.
   НЕ используйте проксирование трафика через Cloudflare.
3. Загрузите и распакуйте этот ZIP на сервер, откройте порты 80/443.
4. Запустите: sudo bash deploy/install-ubuntu.sh ВАШ-ДОМЕН ЭЛЕКТРОННАЯ-ПОЧТА
   Скрипт до установки проверит доступность Supabase из VPS и остановится при ошибке.
5. На компьютере и телефоне БЕЗ VPN: bash deploy/check-access.sh https://ВАШ-ДОМЕН
   Проверьте вход, персонал, синхронизацию, чаты, аудио, видео, фото и push.

Данные, пароли и ключи сервера в архив не помещены. В коде фронтенда
сохраняется только публичный Supabase publishable key — предназначенный для клиента.
Все запросы с авторизацией проходят через HTTPS прокси к существующему Supabase.

НЕ ГАРАНТИРУЕТ доступности на любом операторе: локальные провайдеры могут ограничивать
и VPS, и маршруты к Supabase. Без реального адреса и проверки из сети пользователя
невозможно подтвердить итоговое решение.

Проверка на маршрутизацию: сервер обязан достучаться до
https://xptmcufhuvtcunqzlsme.supabase.co/functions/v1/promysel-compat/health.
Если по адресу VPS это невозможно, нужен другой VPS (включая нейтральный регион),
который доступен с телефонов и имеет связь с Supabase. Произвольное зеркало не поможет.

После выбора и подключения HTTPS-домена ОБЯЗАТЕЛЬНО:
  • В Supabase Auth -> URL Configuration -> Redirect URLs добавить
    https://ВАШ-ДОМЕН/finish-registration.html.
  • В Supabase Edge Functions -> Secrets установить
    PROMYSEL_PUBLIC_ORIGIN=https://ВАШ-ДОМЕН (без завершающего слеша).
    Серверные функции promysel-compat и promysel-device-push уже поддерживают
    эту переменную, но пока не знают будущий домен. До настройки
    ссылки восстановления пароля и приглашений остаются на Cloudflare.
  • На новом домене включить push заново: браузер считает его другим
    источником, старые подписки не переносятся автоматически.
  • Проверить полный вход, письма, фото/аудио/видео, авторизацию,
    восстановление пароля, вход с iPhone и Android без VPN.

Без действующего VPS и адреса сайта этот архив не создаёт публичный URL.

РАЗДЕЛЕНИЕ ВЕРСИЙ: Github main автоматически обновляет только DEV на Cloudflare.
Для Timeweb используется исключительно проверенная ветка stable и стабильный Web-артефакт.
Новые изменения в DEV сами по себе НЕ изменяют рабочий сайт на Timeweb.
